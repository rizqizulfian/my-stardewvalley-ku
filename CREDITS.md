# Credits

## Music

* **"Apple Cider"** by **Zane Little** (2023). Farm daytime theme.
  File: `public/audio/apple-cider.ogg`. Added at the project owner's request; the owner supplied the file.
  Check Zane Little's current licence terms before publishing the game anywhere.

All other music is generated live in code (`src/audio/GenerativeTrack.ts`, tracks in `src/data/music.ts`).

## Sound

Every sound effect and ambience layer (birds, crickets, wind, water, waves, gulls, rain) is synthesised in code
(`src/audio/sfx.ts`, `src/audio/Ambience.ts`). No samples.

## Art

All art is drawn by code at boot from the palette in `src/art/palette.ts`.

## Characters

* **Jotaro** and **Star Platinum** are fan tributes to *JoJo's Bizarre Adventure* by Hirohiko Araki
  (characters owned by Araki / Shueisha), redrawn as original pixel art at the project owner's request.
  Fine for a personal project; remove or replace them before publishing the game commercially.
* **Pak Prabowo** is a friendly tribute villager added at the project owner's request (farming small talk
  only, no politics).
